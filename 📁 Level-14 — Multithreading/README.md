# Level 14 — Multithreading

This level covers the fundamentals of **Multithreading in Java**.

## 📚 Topics Covered

- Creating Threads using `Thread`
- Creating Threads using `Runnable`
- `run()` method
- `start()` method
- `Thread.sleep()`
- `Thread.join()`
- Thread synchronization
- Synchronized methods
- Synchronized blocks
- Thread names
- Thread priorities
- Deadlock
- Deadlock prevention
- Thread-safe counter

## 🎯 Goal

The goal of this level is to understand how multiple threads work in Java and how shared resources can be handled safely.

After completing this level, I should be able to:

- Create and start threads
- Use `Thread` and `Runnable`
- Understand `start()` and `run()`
- Pause threads using `sleep()`
- Wait for a thread using `join()`
- Understand synchronization
- Use synchronized methods and blocks
- Work with thread names and priorities
- Understand how deadlocks occur
- Apply a consistent lock order to avoid deadlocks
- Create a thread-safe counter
