# Level 13 — Exception Handling

This level covers the fundamentals of **Exception Handling in Java**.

## 📚 Topics Covered

- `try` and `catch`
- `finally` block
- Multiple `catch` blocks
- `throw` keyword
- `throws` keyword
- Checked vs Unchecked Exceptions
- Custom Exceptions
- Nested `try-catch`
- Try-with-Resources

## 🎯 Goal

The goal of this level is to understand how Java handles runtime and compile-time errors using **Exception Handling**.

After completing this level, I should be able to:

- Handle exceptions using `try-catch`
- Use `finally` for cleanup code
- Handle different exceptions using multiple `catch` blocks
- Manually throw exceptions using `throw`
- Declare exceptions using `throws`
- Understand checked and unchecked exceptions
- Create custom exceptions
- Work with nested `try-catch`
- Use Try-with-Resources for automatic resource closing
