# Level 10 - HashSet Practice

This folder contains Java practice programs based on the HashSet collection.

## Programs

### Problem 24 - Remove Duplicates
Add duplicate values to a HashSet and observe how duplicate elements are ignored.

**Concepts Used:**
- HashSet
- add()
- size()
- Duplicate handling
- Unique elements

---

### Problem 25 - Check Duplicate Exists
Find duplicate elements from an ArrayList using HashSet.

**Concepts Used:**
- ArrayList
- HashSet
- add()
- containsKey-style duplicate checking
- Enhanced for loop
- Boolean return value of add()

---

### Problem 26 - Union of Two Sets
Find the union of two HashSets using addAll().

**Concepts Used:**
- HashSet
- add()
- addAll()
- Union
- Set operations

---

### Problem 27 - Intersection of Two Sets
Find the common elements between two HashSets using retainAll().

**Concepts Used:**
- HashSet
- add()
- retainAll()
- Intersection
- Set operations

## Concepts Covered

- HashSet
- Unique Elements
- Duplicate Handling
- add()
- size()
- addAll()
- retainAll()
- Union
- Intersection
- ArrayList + HashSet
- Enhanced for loop
