# Level 09 - Deque Practice

This folder contains Java practice programs based on the Deque interface.

## Programs

### Problem 20 - Add From Both Sides
Add elements from both the front and rear of a Deque.

**Concepts Used:**
- Deque
- LinkedList
- addFirst()
- addLast()
- Both-side insertion

---

### Problem 21 - Remove From Both Sides
Remove elements from both the front and rear of a Deque.

**Concepts Used:**
- Deque
- LinkedList
- removeFirst()
- removeLast()
- Both-side removal

---

### Problem 22 - Peek From Both Sides
View the first and last elements without removing them.

**Concepts Used:**
- Deque
- LinkedList
- peekFirst()
- peekLast()
- Both-side access

---

### Problem 23 - Undo System
Create a simple Undo System using Deque by removing the most recent action.

**Concepts Used:**
- Deque
- LinkedList
- addLast()
- removeLast()
- LIFO behavior
- Real-world application of Deque
