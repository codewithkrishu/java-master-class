# Level 06 - Iterator & LinkedList Practice

This folder contains Java practice programs based on Iterator, ListIterator, and LinkedList.

## Programs

**Concepts Used:**
- ArrayList
- Iterator
- iterator()
- hasNext()
- next()
- remove()
- while loop
- Modulus operator (%)
