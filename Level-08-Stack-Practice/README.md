# Level 08 - Stack Practice

This folder contains Java practice programs based on the Stack data structure.

## Programs

### Problem 16 - Reverse a String Using Stack
Reverse a string using Stack by pushing each character and then popping them.

**Concepts Used:**
- Stack
- push()
- pop()
- isEmpty()
- String
- charAt()
- for loop
- while loop
- LIFO (Last In First Out)
